# conflicts 최종 적재 데이터

`conflicts.csv`는 2026-09-23 기준 검색용 분쟁 목록에서 사용자가 선택한
**ACD 분류 대상 12개만 포함하는 DB 적재용 데이터**다. 첨부 ERD와 동일한
7개 컬럼을 사용하며 `display_order`는 포함하지 않는다.

| 파일 | 용도 |
| --- | --- |
| `conflicts.csv` | 최종 12행·7컬럼 데이터. UTF-8 BOM, LF 줄바꿈 |
| `conflicts.metadata.json` | 기준일, 입력·출력 SHA-256, 제외 대상, 행별 좌표 출처·선정 근거 |
| `../../schema.dbml` | 최종 테이블의 컬럼·타입·제약조건 |

## 컬럼

| 컬럼 | DB 타입 | 의미 |
| --- | --- | --- |
| `conflict_id` | VARCHAR(20), PK | 기존 `ucdp_숫자` ID 유지 |
| `conflict_name_en` | VARCHAR(100), NOT NULL, UNIQUE | 검색용 UCDP 원본 영문명 그대로 사용 |
| `conflict_name_ko` | VARCHAR(100), NOT NULL, UNIQUE | 한국어 표시 명칭 |
| `color` | CHAR(7), NOT NULL | 분쟁별 고정된 대문자 `#RRGGBB` 색상 |
| `flag` | VARCHAR(30), NULL 허용 | 이름에 등장하는 국가의 국기 이모지를 공백으로 연결. 이번 12행은 모두 채움 |
| `latitude` | DECIMAL(9,6), NOT NULL | 지도 대표 위치의 위도 |
| `longitude` | DECIMAL(9,6), NOT NULL | 지도 대표 위치의 경도 |

국기 이모지를 보존하도록 MySQL 적재 테이블과 연결은 `utf8mb4`를 사용한다.
CSV 헤더는 데이터 행에서 제외하고 UTF-8 BOM을 처리하는 방식으로 읽는다.
파일은 UCDP ID의 숫자 부분 오름차순이며 DB 조회 순서는 화면에서 지정한다.
색상은 표시용 수동 설정이며 무기 사용량·분쟁 규모를 나타내지 않는다.

검색용 `../ucdp/processed/conflicts.csv`는 후보를 포함한 15개 목록으로 유지한다.
최종 12개만 뉴스 검색하려면 이 최종 CSV의 `conflict_id`와 일치하는 검색 배치만 선택한다.

12개는 현재 목록의 `scope_status=acd_interstate` 대상이다. 이는 과거 연도를 포함한
ACD 분류를 근거로 한 분쟁 목록이며, 연결된 모든 사건이나 2026년 활동이 확정되었다는
의미는 아니다. 이란·이라크의 ACD 국가 간 분쟁 연도는 분석 기간 이전이며,
분석 기간에는 참고 사건이 있어 현재 대상 목록에 포함되어 있다.

## 좌표 선정

사용자 결정에 따라 좌표는 **분쟁당 지도 마커 하나를 표시할 대표 위치**다.
개별 사건 좌표, 전선 경계, 분쟁 전체의 지리적 중심을 의미하지 않는다.
원본 좌표의 소수점 이하 6자리를 보존하며 별도의 위치 정확도를 보장하지 않는다.

1. 같은 분쟁의 `interstate_confirmed` 사건을 우선하고, 없으면 `interstate_reference` 사건을 사용했다.
2. 선택된 사건 중 최신 연도를 사용하고 `where_prec` 1·2인 좌표를 우선했다. 해당 좌표가 없으면 그 연도의 원본 좌표를 사용했다.
3. 같은 위도·경도가 가장 자주 등장하는 위치를 선택했다. 동률은 위도·경도 오름차순으로 정하고, 근거 사건은 해당 위치의 가장 작은 사건 ID로 기록했다.
4. 선택 결과는 참조 JSON의 사건 ID로 고정했다. 재생성 시 좌표가 임의로 바뀌지 않으며, 원본 갱신 후 대표점을 바꾸려면 참조 파일도 검토한다.

예외와 해석상 주의점은 다음과 같다.

- **영국·미국·예멘:** 추출 사건이 0건이므로 예멘 후다이다를 지역 대표점으로 지정했다. 좌표는 이스라엘·예멘 사건 `580798`에서 가져왔으며, 이 사건의 분쟁 연결이나 사건 수를 변경하지 않았다. 원본 검토 목록에는 영국·미국·예멘의 당사자 대응 등을 검토할 사건이 남아 있다.
- **이란·이라크:** 2026년 Candidate의 `interstate_reference` 사건 `626786` 좌표를 사용했다. 해당 사건은 잠정 자료이며 `where_prec=3`이다.
- **에리트레아·에티오피아:** 사건 `229161`의 좌표를 사용했고 `where_prec=5`인 원본 값을 유지했다. 정밀한 사건 위치로 사용하지 않는다.

각 행의 지명, 근거 사건 ID, 원본 분쟁 ID, 연도, 좌표 정밀도 코드, 사건 분류,
원본 종류·버전은 `conflicts.metadata.json`의 `records`에 기록한다.

## 재생성 및 검증

프로젝트 루트에서 실행한다. Python 표준 라이브러리만 사용하며 원본 대용량 CSV를
다시 다운로드할 필요 없이 저장소의 가공 CSV·JSON으로 재생성할 수 있다.

```bash
python scripts/build_conflicts_table.py
python -m unittest tests.test_build_conflicts_table -v
```

수정할 표시 정보와 대표 위치 근거는
`../ucdp/references/conflicts_table.json`에서 관리한다. 영문명은 검색용 목록에서 읽는다.
생성된 CSV를 직접 수정하면 다음 실행 시 덮어쓴다.

생성기는 입력 해시·기준일, 정확한 12개 대상, ID·이름·색상 중복, 필수값·길이,
국기 형식, 좌표 범위·소수 자릿수, 대표점의 사건·교전국 연결을 검증한 후 출력한다.
검증이 실패하면 기존 최종 출력은 교체하지 않는다. 동일 입력으로 재실행하면
CSV와 메타데이터가 바이트 단위로 동일하다.

## 기준일과 사용 범위

- 기준일: 2026-09-23. 분석 기간 설정: 2016-01-01~2026-09-23.
- 연간 자료는 2025년까지, Candidate 입력은 2026년 8월 공개분까지 사용했다.
- 저장된 입력에는 2026-09-01~2026-09-23 자료 공백이 있다. 이 파일의 완성은 선정한
  12개 분쟁의 기준 정보 완성을 의미하며, 신규 분쟁의 누락이 없는 전체 목록을 뜻하지 않는다.
- 현재 대시보드의 두 분쟁 샘플과 가상 기사 생성은 별도로 유지한다. 실제 DB 적재와
  앱 로더 연결은 후속 작업이며, 연결 시 샘플 ID 및 표시 순서 처리도 함께 교체한다.
